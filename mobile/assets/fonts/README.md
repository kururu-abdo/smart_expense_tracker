# Bundled fonts

Manrope and Noto Sans Arabic are distributed under the SIL Open Font License, with the original license files included alongside the fonts.

The files here are static weight instances (400, 500, 600, 700, 800), generated with FontTools from the official Google Fonts variable sources. Noto Sans Arabic uses the normal width axis (100). Keeping the fonts bundled makes the interface independent of a font download at runtime.

Sources:
- https://github.com/google/fonts/tree/main/ofl/manrope
- https://github.com/google/fonts/tree/main/ofl/notosansarabic
